# ADR 0003. Mock не подменяет провайдера

**Статус:** принято (изменение прежнего поведения)

## Контекст

Mock-провайдер нужен, чтобы тесты и E2E шли без ключей и без сети. Сначала он
включался автоматически, когда ни один реальный провайдер не настроен.

## Проблема

В native-режиме (ключей нет, субагентов запускает агент-хост) mock начинал
отвечать за приём цели и планирование. Человек видел осмысленно выглядящий
план и критерии приёмки — сгенерированные заглушкой. Выдуманный результат
был неотличим от настоящего.

## Решение

Mock включается только явным `AGENTOS_ALLOW_MOCK=1`. Без ключей роутер
честно не находит маршрут, а intake и planner уходят на детерминированные
заготовки, помеченные как заготовки. Рассуждает при этом агент-хост — тот,
у кого модель действительно есть.

## Последствия

- Тесты и `agentctl eval run` выставляют флаг сами.
- В native-режиме план по умолчанию — минимальный исполнимый скелет
  (`explore → build → verify`), который агент-хост уточняет под задачу.
- Ни одна ветка кода не выдаёт заглушку за работу модели.

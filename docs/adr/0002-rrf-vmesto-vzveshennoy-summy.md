# ADR 0002. Reciprocal Rank Fusion, а не взвешенная сумма

**Статус:** принято

## Контекст

Поиск по памяти гибридный: BM25 находит имена файлов, идентификаторы и
точные формулировки, векторы — перефразировки. Результаты двух методов надо
объединить.

## Решение

Слияние по рангам: `score = Σ 1 / (k + rank)`, где `k = 60`.

## Почему

Взвешенная сумма требует привести к общей шкале BM25 (неограниченная сверху,
зависит от корпуса) и косинус (от −1 до 1). Веса пришлось бы калибровать —
и перекалибровывать при каждой смене эмбеддера, а эмбеддер здесь меняется
штатно: провайдерский при наличии ключей, локальный хеширующий без них.

RRF работает с рангами и потому нечувствителен к шкалам вообще.

## Последствия

- Абсолютные значения score несопоставимы между запросами; они и не
  используются как порог — только для сортировки.
- Смена эмбеддера не требует перекалибровки поиска (только `reindex_vectors`).

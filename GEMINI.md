# GEMINI.md

Инструкции для работы в этом репозитории — в [AGENTS.md](AGENTS.md).
Прочитай его целиком перед первым действием: там контракт AgentOS.

Коротко, чтобы начать:

```bash
agentctl resume --announce   # первое действие в каждой сессии
agentctl goal "<задача>"     # новая цель от человека
agentctl status              # что сделано, что блокирует, когда продолжит
```

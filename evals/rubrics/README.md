# Рубрики

Пока проверки численные и лежат в `expect` каждого кейса (`evals/missions/*.yaml`):
сколько задач выполнено, были ли провалы, не разросся ли расход токенов,
какой вердикт вынес критик.

Рубрики для качественной оценки (когда результат нельзя свести к числу)
добавляются сюда как отдельные файлы и подключаются полем `rubric` в кейсе.

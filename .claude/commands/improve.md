---
description: Консолидировать память и предложить навыки по итогам работы
---

Прогони эталонные миссии и консолидацию:

```bash
agentctl eval run
agentctl skill list
```

Затем предложи, что стоит закрепить: какие факты и уроки записать в память
(`agentctl memory add`), какие черновики навыков активировать
(`agentctl skill promote <имя>`). Черновик активируется только после того,
как ты убедился, что он не противоречит уже активным навыкам.

---
description: Поставить AgentOS абстрактную цель и запустить работу
---

Поставь цель системе и доведи её до результата:

```bash
agentctl goal "$ARGUMENTS"
```

Дальше действуй по контракту из AGENTS.md: выполняй выданные задания
своими субагентами, возвращай результаты через `agentctl task report`,
после каждой порции вызывай `agentctl resume`, пока миссия не закроется.
